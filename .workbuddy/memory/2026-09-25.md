  循环接缝差异 0.70/255 低于帧间基准 1.81/255（肉眼不可察）；全员角落 alpha=0。
- **重要环境事实**：本机 ffmpeg 9.0 已安装（此前 AGENTS.md 记的"未装"已过时，相关 D+2 录制功能现可端到端验证）。
- 七个坑见 README 第五节，其中最有复用价值的几条：
  ① ImageGen 的 `background:transparent` 在本模型无效（生成白底）→ 透明必须后处理抠图；
  ② 平台水印固定右下角，四角对照才能定量识别，否则污染构图计算；
  ③ 本机 libvpx-vp9 不支持 alpha（四种参数组合全试过）→ 不产出 WebM；
  ④ ffmpeg libwebp 动画有 alpha 累积（64px 角落 2→77）→ 改用 Pillow + disposal=2；
  ⑤ 闭合裁剪公式不可靠（43%~75% 参差）→ 改"导出后实测→闭环校正"3 轮收敛；
  ⑥ 低分辨率 mask 放大做 vignette 有振铃 → 改"白盘+高斯模糊"；
  ⑦ Pillow 的 WebP 动画解码不可靠 → 验证一律用 ffmpeg 独立解帧交叉验证。
- 体积权衡：10fps/5s（慢速呼吸与 15fps 观感无差但省 1/3）；64=84KB、128=266KB、256=775KB，推荐默认用 128 由 CSS 缩放。

## 古风水墨童子版（第四轮 · 方向变更）

- **方向反转**：科技版 alpha ∝ lum（越亮越实）；水墨版是宣纸底，alpha ∝ (纸色 − lum)（越暗越实），
  且宣纸不是纯白（实测 234–237），底色必须实测不能假设 255。

## ★ 09-24e AI 智能内核：从「关键词模板」到「真智能」（webrtc 项目本体，提交 d9d6883）

用户指令："继续升级 重点强化ai相关功能 一定要实现ai的智能"。
判定标准定为：**把关键信息藏在长会最前面、再隔一个话题去问，能不能答对。**

### 做了什么（新文件 sfu/ai/brain.js，零依赖可单测）
1. **BM25 检索器（RAG）**：中文 bigram 分词 + IDF/TF饱和/长度归一 + 时间衰减 + 说话人加成 + 证据块字符预算。
   修掉的硬伤：原 `aiBrain` 只喂 `capTail.slice(-8)`（最近 8 条），长会早期信息问不出来。
2. **ConversationMemory**：环形上限 8 轮 + 长答案截断 + **指代时把上一轮问题一起检索**（廉价指代消解）。
3. **classifyIntent**：LLM 意图分类替代正则。修掉"帮我整理下今天聊了啥"→ 老正则失明 → 纪要没生成却回"好的我来整理"。
   动作型高置信时短路省 LLM 调用；LLM 返回未知标签 fail-safe 落回规则。
4. **extractActions**：行动项结构化 `{owner,task,due}`。**架构决定：内容交 LLM、格式交代码**（确定性渲染 markdown 表格，两轨格式一致）。
5. **操作员 ReAct 闭环**：每步收集服务端可确定的三类观测（转发门禁结果/控制权/执行轨迹）→ 喂回 LLM 判断达成与修正（≤4 轮）。
   结论三档措辞，出现过输入丢弃就报"可能未完全生效"。
6. **证据链 UI**：气泡摊开 `📚 检索 N 条取 M 条 · 💬 第 K 轮 · 🎯 意图`。

### 本轮实修的真缺陷（都记进 AGENTS 坑 41~44）
- **`RoomBrain.answer` 漏 `memory.push`**：Memory 类单测全过但没人往里写 → 记忆机制整体是死的。
  **教训：模块对了 ≠ 接线对了，有状态写入的功能必须有"写进去没有"的断言。**
- **正则贪婪**：`压测报告我负责`→owner=`压测报告我`；`我们需要跟进`→`们需要`。
  修法：lookbehind `(?<![\u4e00-\u9fff])` 近似中文词边界 + 集体词表拦截。
- **基于不存在的 `remote-input-ack` 写闭环**：我"理所当然"写了监听，grep 后发现客户端从不回此 ack。
  照此实现将永远误判"帧未送达"并疯狂重试。→ 改用服务器转发时的在线状态。
  **纪律：涉及"某事件/字段存在吗"，先 grep 证伪再写。**
- **验证脚本消息竞态**：`emitAck` 回执先到、答案后到 → 抓到上一轮回复，症状伪装成"记忆失效"。
  修法：先清空数组、再 emit、按 `ts >= t0` 过滤。
- **test-sfu-signaling 端口冲突时原为"警告后继续跑"** → 产出会说谎的测试（实测让 `/api/rooms?token=` 假失败，
  一度以为门禁改坏；真实原因是我后台起的服务器占了 3001 且用正式库，测试账号不是 admin）。
  改为**明确失败 + 给修复指引**。**宁可红得清楚，不要绿得可疑。**
