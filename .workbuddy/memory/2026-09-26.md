- **修复**：循环方案改为 **palindrome（正放+倒放）**——`base + base[-2:0:-1]`，
  数学上严格无缝（接缝 1→0 恒等于 0→1 的逆），任何慢动作倒放都自然（呼吸/sway/眨眼）。
  xfade 方案彻底废弃。**教训：交叉淡化修循环只适合镜头静止且画面微动的素材；
  有人物/物体位移的素材必然重影。**
- 重跑 idle：`avatar-3d-{64·128·256}.webp`（82帧 palindrome，256=787KB），
  接缝 6 帧拼图逐帧确认无重影，alpha 校验角落 0-1 / 脸 255。

### 说话状态动画（用户"增加说话状态"）
- **speaking 不能倒放**（倒放=倒着说话）→ hardcut 模式：尾半段找与首帧差异最小的帧硬切。
- **帧差分要加 alpha 质量惩罚**：纯 RGB 均差对局部特效不敏感。第一版说话视频
  源里 20-28 帧带 AI 生成的烟雾特效（mass 0.48-0.51 vs 正常 0.467，RGB差 0.14-0.20），
  纯 RGB 差分把切点选在了 33（含烟雾帧）；`frame_diff += 2*|mass_a - mass_b|` 后
  能识别特效帧。**且相似度必须基于抠好的 RGBA 帧算**（未抠 RGB 帧 alpha 恒 255，
  惩罚无效）——build_anim.py v2 已改为先抠图再定序。
- **治本**：用 negative_prompt（smoke/clouds/fog/sparkles/particles…）+ 正 prompt
  强调"动作克制、头身位置不变"重新生成视频。新视频无烟雾、pose 稳定，
  hardcut 切在帧 40（diff=0.028，41 帧 2.7s 循环，几乎无感）。
  **教训：AI 视频生成的环境特效（烟/光斑）是循环动画的大敌，prompt 里必须显性排除。**
- 产物：`avatar-3d-talk-{64·128·256}.webp`；部署为 `xiaoming-talk.webp` / `xiaoming-talk-sm.webp`。

### 比例修复（用户截图"实际比例不对"：圆盘跑偏+脸被放大裁切）
- **定位 bug**：`.ai-face-wrap { position:absolute; inset:0; width:82% }` 过约束——
  abs 定位 left/right/width 全指定时按**左对齐**放置（top/bottom/height 同理），
  圆盘跑到格子左上角被 overflow 裁切。改 `left/top:50% + translate(-50%,-50%)` 显式居中。
- **比例 bug**：`img { width:100%; height:100% }` 会把 img 拉伸成**容器的比例**，
  非正方形容器里 object-fit:cover 按被拉伸的框二次裁切 = 人物放大裁脸。
  对照实验（200×200 方盒正常 / 200×320 高盒必现 zoom）实锤。
  正确写法：**容器只给 `width` + `aspect-ratio:1` 锁死正方形**，img 填满即恒 1:1。
- 验证方法：`msedge.exe --headless --screenshot=... --virtual-time-budget=3000 file:///...`
  （本机无 agent-browser/Chrome，Edge 无头截图可用；截图输出要绝对路径）。
  用**真 style.css + 真 markup** 复现渲染后逐帧核对，不猜 CSS。
