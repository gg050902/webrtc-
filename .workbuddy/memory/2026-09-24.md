## 工程约定（后续务必遵守）

- **AI 断言不得假设"一定没有 key"**：信令测试从 `/config.json` 读 `aiEnabled` 后断言分叉
  （见 AGENTS 坑 39）；真模型质量抽查只放 `npm run test:ai`（无 key 自动 skip）。

  断言按 `children` 聚合读文本。
