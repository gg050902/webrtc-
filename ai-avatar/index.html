AI 助理动态头像

照你给的参考照复刻：蓬松的中分刘海、平行双眼皮的温和眼型、 挺直鼻梁、收窄的下颌，唇上点一笔朱砂。单色炭笔线条，除此无他—— 线条越少，越经得起缩到 40px。矢量绘制，CSS 驱动动画。

形象

五种情绪由眉、眼、嘴三组形态切换组合而成——结构不变，所以切换瞬时且无跳变。 生动感来自三处：一是各动画周期刻意错开（呼吸 5.4s、摆头 7.3s、眨眼 4.7s、挑眉 8.9s， 互不成整数倍，永不同步）；二是说话时嘴有开合节奏而不只是张开； 三是眉毛每隔几秒会不经意挑一下。

尺寸

矢量无损，40px 与 180px 是同一份代码。主体外一圈留白经过收敛， 圆形裁切不会碰到外环。

集成

<!-- 内联 SVG（或存成 avatar.svg 用 <img> 引用） -->
<div class="av"> …SVG… </div>

/* 颜色自适应深浅：用 currentColor，父级设 color 即可 */
.av { color: #0a0a0a; }        /* 浅色界面 */
body.dark .av { color: #fff; } /* 深色界面 */

/* 切状态：只换 class，结构不变 */
el.className = 'av ' + state;   // st-idle / st-listen / st-speak / st-think / st-happy
