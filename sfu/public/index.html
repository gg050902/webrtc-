⚠️ 摄像头 / 麦克风被浏览器禁用了
当前是 http + IP 访问，浏览器只在安全上下文 （https:// 或 localhost）才允许摄像头、麦克风与 Service Worker。 地址栏那句「不安全」也是同一条规则 —— 这不是代码 bug，是浏览器的安全底线。
① 局域网自签 https（自己在局域网演示用）
npm run start:lan
会开 https://<局域网IP>:3443，摄像头即可用；但这是自签证书， 浏览器仍会提示一次「不是私密连接」，需点 高级 → 继续前往（也可直接双击 start-lan.bat）。Android 一般能直接跳过； iOS Safari 要手动信任：设置 → 通用 → VPN与设备管理 / 关于本机 → 证书信任设置 → 打开该证书的开关，否则连不上。
② 公网受信任 https（推荐：发给别人 / 手机看）
cloudflared tunnel --url http://localhost:3001
一条命令拿到 https://xxx.trycloudflare.com， 自动是受信任证书、无任何警告，手机和别人的电脑都能直接打开。 没装 cloudflared 先装：winget install --id Cloudflare.cloudflared。 边界：隧道只走 HTTP / WebSocket（信令），SFU 的媒体是 UDP 过不去 —— 要给别人开完整会议，请发布 Mesh 版：node scripts/publish.js --tunnel。
一句话结论：自签证书只适合自己在局域网演示；要给别人 / 手机无障碍访问， 用隧道拿受信任证书（不会有「不安全」警告）。
