會真人语音金标准

录一份"我自己念的、带标准答案"的语音，让 npm run bench:asr-golden 量得出**准确率**（此前只有延迟有尺）。 · 回会议页 · 观测面板

为什么要录这个

所有自动化测试喂的都是合成语音，而它每句都写着「小明」——**结构上测不出误唤醒**；它的电平节奏也不是真人的。 这个项目已经被合成数据与真人数据给过的**相反答案**烫过两次（自测 1.4s / 真会中位 3.9s；回归全绿 / 真麦克风 -56dB 被当静音删）。 所以"这套语音真人开会到底能不能用"这个问题，只有你念一遍才答得了。

录完在终端跑 npm run bench:asr-golden：它会把这批真人录音分别喂给本机 Qwen3-ASR 与 whisper， 出字级错误率（CER）对照表。产物只落在 sfu/voice-golden/（已进 .gitignore，不会提交）。
