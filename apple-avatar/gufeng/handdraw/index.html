古风小人头

手绘矢量版。逐笔控制造型，不存在 AI 生成人物常见的五官崩坏； 动画由 CSS 矢量插值驱动，数学级流畅，且体积只有几 KB。

形象

五个状态靠眼形与嘴形的切换实现（睁眼/弯眼 × 微笑/张开/平直），结构不变， 因此切换是瞬时的、不会有跳变；呼吸浮动与眨眼由 CSS 关键帧驱动，任何帧率下都平滑。

尺寸

矢量放大不失真，40px 与 200px 共用同一份代码。

集成

<!-- 直接内联 SVG，或存成 .svg 用 <img> 引用 -->
<div class="avatar st-idle"> …SVG… </div>

<!-- 切状态：只换 class -->
el.className = 'avatar ' + (speaking ? 'st-speak' : 'st-idle');

/* 关键动画 */
.avatar   { animation: breathe 4.2s ease-in-out infinite; }
.avatar .eye { animation: blink 4.6s ease-in-out infinite; }
