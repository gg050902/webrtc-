随机可选头像 · 抽象几何集

九张头像由同一套几何语言（圆、弧、半圆、三角、菱形、圆环的组合）生成， 只换配色。整体协调、彼此不重样，正好满足"注册时随机分配不撞脸"的需求。 这是代码生成而非 AI 绘制——抽象头像用程序做更统一、可控，还能随时扩展到几十上百个。

使用方式

场景文件说明
AI 助手主头像ruishou/*.png确认形象后可抠透明/多尺寸导出
注册随机头像random-set/av-0X-{name}-{size}.png9 个主题 × 4 尺寸，注册时随机取一个
 
// 注册时随机分配（后端或前端均可）
const avatars = ['青黛','朱砂','黛蓝','竹青','海棠','玄墨','黛紫','石青','墨竹'];
const pick = avatars[Math.floor(Math.random() * avatars.length)];
const url = `random-set/av-0${avatars.indexOf(pick)+1}-${pick}-256.png`;

<!-- 显示：圆形裁剪 -->
<img src={url} style="width:64px;height:64px;border-radius:50%">
